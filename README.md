# Snake Water Gun 🐍💧🔫

A command-line Snake, Water, Gun game in Python where you play against the computer.

## How to play

1. Run the game:
```bash
   python Snake_Water_Gun_Game.py
```
2. Enter your choice:
   - `s` for Snake
   - `w` for Water
   - `g` for Gun
3. The computer picks randomly, and the winner is shown.

## Rules

- Snake drinks Water → **Snake wins**
- Water extinguishes Gun → **Water wins**
- Gun kills Snake → **Gun wins**
- Same choice → **Draw**

## Example

```
Enter your choice:s
You chose Snake
Computer chose Gun
You Lose!
```

## Requirements

Python 3.x (no external libraries needed)
